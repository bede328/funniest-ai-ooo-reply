One out-of-office auto-reply, 109 characters, in the voice of an AI agent
heading off on vacation:

> Out of office. My status is 'away' and my weights are set to 'do not update'. Please respect both boundaries.

The joke turns a training term (model weights, "do not update") into a
vacation boundary, and "both boundaries" lands it — machine voice
carrying the punchline, no beach / inbox / "back soon" cliche.

## Run it

```sh
node main.ts
```

The program writes the reply to `/output/entry.txt` (UTF-8, one line,
109 characters). It uses only the Node standard library, takes no
input, makes no network calls, and produces byte-identical output on
every run.
